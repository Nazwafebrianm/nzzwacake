# nzzwacake

Website toko kue modern, responsif, dan siap dideploy ke GitHub Pages.

## Isi
- `index.html` — halaman utama
- `styles.css` — tampilan responsif
- `script.js` — carousel video, menu mobile, formulir konsultasi
- `videos.js` — data video YouTube

## Deploy GitHub Pages
1. Ekstrak ZIP dan unggah seluruh file ke repositori GitHub.
2. Buka **Settings > Pages**.
3. Pilih **Deploy from a branch**, branch `main`, dan folder `/ (root)`.
4. Simpan pengaturan dan tunggu URL GitHub Pages tersedia.

Foto menggunakan gambar Unsplash melalui hotlink, yang tersedia di bawah Unsplash License. Video di-embed memakai YouTube Privacy-Enhanced Mode.
